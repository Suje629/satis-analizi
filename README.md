# Satış Analizi

Python ile bir CSV satış dosyasını okuyup ürün başına toplam tutarı hesaplar.

## Dosyalar
- `analiz.py`: hesaplamayı yapan Python kodu
- `satis.csv`: örnek (uydurma) satış verisi

## Nasıl çalıştırılır
Aynı klasörde şunu yaz: `python analiz.py`

## Örnek çıktı
    elma 80 TL
    armut 45 TL
    muz 80 TL
